# Project Structure

> Generated by engine skill. Any AI entering this project should read this first.

## Directory Overview

| Directory | Purpose | Who writes |
|---|---|---|
| `01_data/raw/` | Yearbook, remote-sensing raw data | Read-only; AI must not overwrite |
| `02_literature/` | Search keywords, Boolean strings, exported RIS/BibTeX | read skill search phase |
| `03_papers/Article/` | Per-paper notes `<title>.md` | **read skill only** |
| `03_papers/ArticleMatrices.md` | Quick-locate card matrix | read skill |
| `03_papers/_reading-progress.md` | Read / to-read / abandoned | read skill |
| `04_experiments/code/` | Main-line test scripts | You and AI |
| `04_experiments/results/` | Script intermediate outputs | Test scripts |
| `04_experiments/logs/` | Experiment logs | You and AI |
| `05_outline/` | Central thesis, technical roadmap, section outline | You and AI discuss |
| `06_temp/` | AI process files, test scripts, drafts | AI free to write; clean before submission |
| `07_draft/` | **write skill final draft workspace** | write skill |
| `08_figures/` | **p skill figure projects/data/final images** | p skill |

## Hard Rules

1. **read skill writes only to `03_papers/`; write skill only to `07_draft/`; p skill only to `08_figures/`** — ask the user before writing outside these.
2. **`01_data/raw/` is read-only.** Computed results go to `04_experiments/results/`; never overwrite raw files.
3. **Unsure where something goes → `06_temp/`.** Do not scatter misc files in `07_draft/`.
4. **Each section's draft** lives in `07_draft/<section>/`: `<section>.md` is the draft, `<section>data.md` is the traceability process file.
