| `07_draft/` | **write skill final draft workspace** | write skill |
| `08_figures/` | All figure projects, data, final outputs | p skill |

## Hard Rules

1. **read skill only writes `03_papers/`, write skill only writes `07_draft/`**; ask the user before writing elsewhere.
2. **`01_data/raw/` is read-only**. Results go to `04_experiments/results/` or figure folders; never overwrite raw files.
3. **Uncertain files go to `06_temp/`**; do not scatter misc files in `07_draft/`.
4. **Each chapter draft** lives in `07_draft/<section>/`: `<section>.md` is the manuscript, `<section>data.md` is the traceability file.
