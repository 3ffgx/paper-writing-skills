# 项目结构说明

> 本项目由 engine skill 生成。任何 AI 进入本项目前先读这份，再动手。

## 目录一览

| 目录 | 用途 | 谁写 |
|---|---|---|
| `01_数据处理/原始数据/` | 年鉴、遥感等原始数据 | 只读，AI 禁止覆盖 |
| `02_文献检索/` | 检索关键词、检索式、导出的 RIS/BibTeX | read skill 检索阶段 |
| `03_论文仓库/Article/` | 每篇论文笔记 `<题目>.md` | **read skill 专用** |
| `03_论文仓库/ArticleMatrices.md` | 论文目录卡片，AI 快速定位 | read skill |
| `03_论文仓库/_阅读进度.md` | 已读/待读/放弃 | read skill |
| `04_实验测试/代码/` | 主线测试脚本 | 你和 AI |
| `04_实验测试/结果输出/` | 脚本跑出的中间结果 | 测试脚本 |
| `04_实验测试/日志/` | 实验日志 | 你和 AI |
| `05_主线设计/` | 论文中心论点、技术路线、章节大纲 | 你和 AI 讨论 |
| `06_临时文件/` | AI 过程文件、试跑脚本、废稿 | AI 随便写，定稿前清理 |
| `07_写入参考/` | **write skill 最终稿工作区** | write skill |
| `08_图/` | **p skill 图件工程/数据/最终图** | p skill |

## 硬规则

1. **read skill 只写 `03_论文仓库/`，write skill 只写 `07_写入参考/`，p skill 只写 `08_图/`**；越界写文件前先问用户。
2. **`01_数据处理/原始数据/` 只读**。算完的结果写到 `04_实验测试/结果输出/`，不许覆盖原始文件。
3. **不确定放哪的东西扔 `06_临时文件/`**，不要在 `07_写入参考/` 里乱放杂项。
4. **每章成稿**在 `07_写入参考/<章名>/` 下：`<章名>.md` 是成稿，`<章名>data.md` 是溯源过程表。
