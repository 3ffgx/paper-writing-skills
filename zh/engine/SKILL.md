# engine — 项目骨架一键生成

用户在某个项目根目录下输入 `ENGINE START`，本 skill 自动在该目录生成标准文件夹结构。

## 触发条件

- **唯一触发**：用户输入 `ENGINE START`（大小写不限、可带前后空格）。
- 其他情况（包括"帮我建个项目""初始化文件夹"）**不自动执行**，先问用户是不是要 ENGINE START。

## 执行流程

1. **确认项目根目录**：问用户"在哪个目录下建骨架"。如果用户当前对话里已经给出路径（比如"在 D:\论文\河南省 下建"），直接用；没给就问。
2. **检查是否已存在**：如果目标目录里已经有 `01_数据处理` 等文件夹，先告诉用户"骨架已存在，要不要重建/跳过"，不要无脑覆盖。
3. **生成文件夹**（结构见下）。
4. **在根目录写 `_README.md`**：把各目录用途和写入规则落盘，后续任何 AI 进项目先读这份。
5. **在 `05_主线设计/` 写三份模板**：
   - `论文大纲.md`（空的章节树，用户自己填）
   - `术语表.md`（空表，write skill 写作过程中逐步积累）
   - `图表清单.md`（空表，按图号登记图/表，附"分析模块→图类型"对照表）
6. **在 `04_实验测试/` 建 `日志/` 子目录**，放一份日志模板，用户跑分析时追加记录。
7. **回报**：告诉用户建好了哪些目录、模板在哪。

## 标准骨架

```
<项目根>/
├── 01_数据处理/
│   └── 原始数据/            # 年鉴、遥感等原始数据（只读，AI 禁止覆盖）
├── 02_文献检索/             # 检索关键词、检索式、导出的 RIS/BibTeX
├── 03_论文仓库/             # read skill 工作区
│   ├── Article/            #   每篇论文笔记：<题目>.md
│   ├── ArticleMatrices.md  #   目录卡片
│   └── _阅读进度.md
├── 04_实验测试/
│   ├── 代码/               # 主线测试脚本（python/r 等）
│   ├── 结果输出/           # 脚本跑出的中间结果
│   └── 日志/               # 实验日志
├── 05_主线设计/             # 论文中心、实验方案、章节大纲
├── 06_临时文件/             # AI 过程文件：试跑脚本、中间数据、废稿
├── 07_写入参考/             # write skill 最终稿工作区
│   └── (按章节建子文件夹，如 1引言/、2.2核算方法/)
└── 08_图/                  # p skill 工作区：所有图件工程、数据、最终图
    ├── origin/             #   Origin工程（.opj）+ 数据 + 最终图
    ├── arcmap/             #   ArcMap工程（.mxd）+ shp + 最终图
    ├── geoda/              #   GeoDa项目文件
    └── python/             #   Python画图脚本 + 输出图
```

## 写入规则（写进 _README.md）

- **01_数据处理/原始数据/ 只读**：任何 AI 不许修改、删除、覆盖原始文件。
- **02_文献检索/**：放检索策略，不放论文全文。
- **03_论文仓库/**：read skill 专用，其他 skill 不往里写。
- **04_实验测试/结果输出/**：脚本输出统一落这，不要散在代码旁边。
- **05_主线设计/**：论文中心论点、技术路线图、章节大纲的草稿。
- **06_临时文件/**：AI 随便写，但**项目定稿前要清理**；不确定放哪的东西先扔这。
- **07_写入参考/**：write skill 专用，每个章节一个子文件夹，里面 `<章名>.md` 是成稿、`<章名>data.md` 是溯源过程表。
- **08_图/**：p skill 专用，按平台（origin/arcmap/geoda/python）分子文件夹，每个图一个子文件夹（`图X_图名/`），里面放工程文件+绘图数据+最终图。

## 与其他 skill 的衔接

- `read` skill 的输出根目录 = `03_论文仓库/`。
- `write` skill 的输出根目录 = `07_写入参考/`。
- `p` skill 的工作目录 = `08_图/`。
- 画图数据从 `01_数据处理/原始数据/` 或 `04_实验测试/结果输出/` **复制**到对应图件文件夹，原始数据不动。

- [ ] `05_主线设计/论文大纲.md` 模板已生成（空的章节树，用户自己填）。

- [ ] `05_主线设计/图表清单.md` 模板已生成（空表+模块对照表）。
- [ ] `04_实验测试/日志/` 目录已建，放了日志模板。
