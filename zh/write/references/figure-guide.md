# 通用图表决策表

> 不管你写什么资源环境类论文（水资源足迹/碳足迹/生态承载力/...），
> 做了哪种分析模块，就固定对应哪种图、什么数据、什么展示形式。
> 写 Results 前，先盘点你做了哪些分析模块，再从这张表里挑出该画的图。

## 按分析模块对应图表

| 分析模块 | 必画图 | 可选图 | 需要的数据 | 展示形式 | 用什么工具 |
|---|---|---|---|---|---|
| **核算结果概览** | 各分量生态足迹构成图 | 核算总表 | 各土地分量EF、EC、赤字 | 堆叠柱状图（分分量）/饼图 | Origin |
| **时间变化** | 人均EF/EC逐年折线图 | 逐年赤字变化图、趋势检验图 | 逐年、逐市/区域的指标值 | 多线折线图（按市/按区域）+ 显著性标记 | Origin |
| **空间格局** | 多年平均空间分布图 | 某一年典型期空间分布图 | 多年均值 + 行政边界shp | 分级设色图（自然断点/相等间隔） | ArcMap |
| **空间自相关** | Moran's I散点图 + LISA聚类图 | Moran's I逐年变化折线图 | 空间权重矩阵 + 逐年指标值 | 散点图（四象限）+ 聚类分布图（HH/LL/HL/LH） | GeoDa + ArcMap |
| **驱动因素分解（LMDI）** | 各效应贡献堆叠柱状图 | 逐年效应变化折线图 | 分解后各效应（规模/结构/效率）贡献值 | 堆叠柱状图（分效应）+ 正负值区分色 | Origin/Python |
| **回归分析（STIRPAT等）** | 回归系数图 | 回归结果表 | 标准化回归系数、p值、R² | 森林图（系数+置信区间）/ 系数表 | Origin/Python |
| **预测** | 历史vs预测折线图（含验证段） | 预测精度对比表 | 历史序列 + 预测值 + MAPE/R² | 折线图（观测实线+预测虚线，验证段对比） | Origin |
| **研究区概况** | 研究区位图 | 行政区划图 | 边界shp + 重要地理要素 | 分级设色/晕渲，标省会、河流 | ArcMap |

## 表 vs 图怎么分

- **表**：放精确数值、回归结果、分解贡献值（读者要查具体数字）
- **图**：放趋势、格局、对比关系（读者要看形态和空间分布）
- **同一个数据不要既画图又列表**——挑一种。趋势用图，精确值用表。

## write skill 引用图的方式

正文里写："如图X所示，……"
- 图号从 `05_outline/figure-list.md` 取
- 图题不写在正文里，Word 插图时统一加
- 正文第一次提到某图时写"如图X所示"，后面再提可以省略
- 图号按正文出现顺序排，不是按章节排

## 数据存放规则

画图的工程、数据、最终图统一放 `08_figures/<platform>/FigX_name/` 下：
- `08_figures/origin/Fig2_perCapitaWEF/Fig2.opj`（Origin工程）
- `08_figures/origin/Fig2_perCapitaWEF/Fig2_data.csv`（绘图数据，从 `01_data/raw/` 或 `04_experiments/results/` 复制）
- `08_figures/arcmap/Fig3_spatialPattern/Fig3.mxd`（ArcMap工程）
- `08_figures/python/Fig7_forecast/plot.py`（Python脚本）

**铁律：图上每个数据点必须能在源文件里找到。** figure-list.md 里的"数据文件"字段必须填具体CSV/shp路径，不能写"年鉴""统计公报"这种模糊来源。审稿人要查数据时，能从图→CSV→原始数据一路追溯。

## 导出规范（中文SCI最低要求）

| 项目 | 要求 |
|---|---|
| 尺寸 | 先查目标期刊投稿须知；一般双栏图宽160-180mm，单栏80-90mm |
| 字号 | 图中文字（坐标轴/图例/标注）最终印刷后5-8pt，Origin里设10-12pt再缩放 |
| 字体 | Arial/Helvetica无衬线，中文用宋体或黑体，全图统一 |
| 配色 | 一中性色+一强调色；不彩虹色图；黑白打印也能区分（用线型/标记形状辅助，不只靠颜色） |
| 导出 | 矢量优先：Origin导出EMF/PDF；ArcMap导出EMF/PDF；投稿需要TIFF时300-600dpi |
| 图题 | 不写在图内，Word插图时在图下方加；正文引用"如图X所示" |
| 数据标签 | 如果图上标了n、显著性星号（*/**/***）、误差棒，要在图注或正文写清n和检验方法 |
