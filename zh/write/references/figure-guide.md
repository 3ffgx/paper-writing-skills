# 通用图表决策表

> 适用于理工科/社会科学实证论文（资源环境、材料、生物、经济等定量研究均可参照）。
> 做了哪种分析模块，就固定对应哪种图、什么数据、什么展示形式。
> 写 Results 前，先盘点你做了哪些分析模块，再从这张表里挑出该画的图。
> 下表中"资源环境类"行仅为示例，替换为你的研究领域对应模块即可。

## 按分析模块对应图表

| 分析模块 | 必画图 | 可选图 | 需要的数据 | 展示形式 | 常用工具 |
|---|---|---|---|---|---|
| **结果概览/构成** | 各分量占比图 | 总表 | 各分项值 | 堆叠柱状图/饼图/条形图 | Origin/Excel |
| **时间变化** | 逐年/逐期趋势线 | 趋势检验图、斜率图 | 逐期指标值（分组） | 多线折线图 + 显著性标记 | Origin/Python |
| **空间分布** | 空间分布图 | 典型期对比图 | 指标值 + 行政边界shp | 分级设色图（自然断点/相等间隔） | ArcMap/QGIS |
| **空间自相关** | Moran's I散点图 + LISA聚类图 | Moran's I时间变化图 | 空间权重矩阵 + 逐期指标值 | 散点图（四象限）+ 聚类分布图（HH/LL/HL/LH） | GeoDa + ArcMap |
| **因素分解（LMDI等）** | 各效应贡献堆叠柱状图 | 逐年效应变化图 | 分解后各效应贡献值 | 堆叠柱状图（分效应，正负区分色） | Origin/Python |
| **回归/敏感性分析** | 回归系数森林图 | 回归结果表 | 标准化系数、p值、R² | 森林图（系数+置信区间）/ 系数表 | Origin/Python |
| **预测/模拟** | 历史vs预测折线图（含验证段） | 预测精度对比表 | 历史序列 + 预测值 + 误差指标 | 折线图（观测实线+预测虚线） | Origin/Python |
| **研究区/对象概况** | 区位图 | 样本分布图 | 边界shp + 地理要素 | 分级设色/晕渲，标关键要素 | ArcMap |
| **实验对比（材料/生物类）** | 实验组vs对照组柱状图 | 显著性标记图 | 各组测量值 + n | 柱状图 + 误差棒 + 显著性星号 | Origin/GraphPad |
| **流程/机理示意** | 技术路线图/机制示意图 | 概念框架图 | 无定量数据 | 框图/流程图（Visio/draw.io导出矢量） | Visio/PPT |

## 表 vs 图怎么分

- **表**：放精确数值、回归结果、分解贡献值（读者要查具体数字）
- **图**：放趋势、格局、对比关系（读者要看形态和空间分布）
- **同一个数据不要既画图又列表**——挑一种。趋势用图，精确值用表。

## write skill 引用图的方式

正文里写："如图X所示，……"
- 图号从 `05_outline/figure-list.md` 取
- 图题不写在正文里，Word 插图时统一加
- 正文第一次提到某图时写"如图X所示"，后面再提可以省略
- 图号按正文出现顺序排，不是按章节排

## 数据存放规则

画图的工程、数据、最终图统一放 `08_figures/<platform>/FigX_name/` 下：
- `08_figures/origin/Fig2_trend/Fig2.opj`（Origin工程）
- `08_figures/origin/Fig2_trend/Fig2_data.csv`（绘图数据，从 `01_data/raw/` 或 `04_experiments/results/` 复制）
- `08_figures/arcmap/Fig3_spatial/Fig3.mxd`（ArcMap工程）
- `08_figures/python/Fig7_forecast/plot.py`（Python脚本）

**铁律：图上每个数据点必须能在源文件里找到。** figure-list.md 里的"数据文件"字段必须填具体CSV/shp路径，不能写"年鉴""统计公报""实验记录"这种模糊来源。审稿人要查数据时，能从图→CSV→原始数据一路追溯。

## 导出规范（中文SCI最低要求）

| 项目 | 要求 |
|---|---|
| 尺寸 | 先查目标期刊投稿须知；一般双栏图宽160-180mm，单栏80-90mm |
| 字号 | 图中文字（坐标轴/图例/标注）最终印刷后5-8pt，Origin里设10-12pt再缩放 |
| 字体 | Arial/Helvetica无衬线，中文用宋体或黑体，全图统一 |
| 配色 | 一中性色+一强调色；不彩虹色图；黑白打印也能区分（用线型/标记形状辅助，不只靠颜色） |
| 导出 | 矢量优先：Origin导出EMF/PDF；ArcMap导出EMF/PDF；投稿需要TIFF时300-600dpi |
| 图题 | 不写在图内，Word插图时在图下方加；正文引用"如图X所示" |
| 数据标签 | 如果图上标了n、显著性星号（*/**/***）、误差棒，要在图注或正文写清n和检验方法 |
